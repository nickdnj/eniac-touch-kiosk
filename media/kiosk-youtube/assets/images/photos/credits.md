## Notes
- **P2 has a caption baked into the original image** ("Replacing a bad tube meant checking among ENIAC's 19,000 possibilities."), which is also the wrong figure for our script (18,000). The `-clean` file crops the bottom 69 px off (1239x955), removing the caption. Use the clean file only. The original is kept for reference.
- P1 and P3 have no text in the image. P1 is only 1340x1024, so expect softness on a 16:9 crop with a push-in.
